Test Data Generator — C++17
← VOLTAR À WX-TOOLS

Utilitário de linha de comando que gera dados sintéticos reproduzíveis em CSV, JSON e SQL. Com a mesma seed e os mesmos parâmetros, produz saídas idênticas. Gera arquivos para testes e demonstrações sem conexão direta com bancos de dados.

Comandos

ComandoDescrição
generateGera registros sintéticos no formato escolhido.
selftestExecuta a bateria consolidada de testes internos.
--helpExibe a ajuda de uso.
--versionExibe a versão.

Opções de geração

OpçãoDescrição
--rows NQuantidade de registros; padrão 10, máximo 100.000.000.
--seed NSeed determinística de 64 bits sem sinal; padrão 2026.
--format Fcsv, json ou sql; padrão csv.
--output PATHArquivo de saída; use - para stdout (padrão).
--table NAMENome da tabela nos INSERTs SQL; padrão DadosTesteSinteticos.

Exemplos — PowerShell

E:\@LIB-C++\bin\wxt-cpp-050-test-data-generator.exe generate --rows 100000 --seed 2026 --format csv --output dados.csv

E:\@LIB-C++\bin\wxt-cpp-050-test-data-generator.exe generate --rows 10 --format json --output dados.json

E:\@LIB-C++\bin\wxt-cpp-050-test-data-generator.exe generate --rows 50 --format sql --table DadosTesteSinteticos --output dados.sql

E:\@LIB-C++\bin\wxt-cpp-050-test-data-generator.exe selftest

Determinismo e segurança

O gerador utiliza seed explícita para repetir os mesmos registros e inclui testes de equivalência byte a byte para CSV, JSON e SQL. Os e-mails são sintéticos e utilizam domínio reservado para exemplos. Os comandos apenas geram texto ou arquivos; não executam instruções no SQL Server.
