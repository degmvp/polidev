POLYDEV | WX-TOOLS | C++ | 036 — SQL Query Performance Analyzer

Visão geral

Utilitário C++17 e ODBC para inspecionar estatísticas de consultas do SQL Server. Executa somente consultas de leitura sobre DMVs, sem alterar objetos ou dados.

Comandos

ComandoOperação
topConsultas em cache com maior CPU total
readsConsultas em cache com mais leituras lógicas totais
durationConsultas em cache com maior duração total
activeRequisições ativas do banco, por tempo decorrido

Exemplos de execução

wxt-cpp-036-sql-query-performance-analyzer.exe top --server ".\WSRV25" --db WX_RECOVERY_LAB
wxt-cpp-036-sql-query-performance-analyzer.exe reads --server ".\WSRV25" --db WX_RECOVERY_LAB --limit 10
wxt-cpp-036-sql-query-performance-analyzer.exe duration --server ".\WSRV25" --db WX_RECOVERY_LAB
wxt-cpp-036-sql-query-performance-analyzer.exe active --server ".\WSRV25" --db WX_RECOVERY_LAB

Compilação

Visual Studio 2022, C++17, Windows SDK e ODBC Driver 18 for SQL Server instalados.

cl /std:c++17 /EHsc /W4 /utf-8 wxt-cpp-036-sql-query-performance-analyzer.cpp odbc32.lib /Fe:wxt-cpp-036-sql-query-performance-analyzer.exe

Requisitos e observações

  • Autenticação integrada do Windows.
  • ODBC Driver 18 for SQL Server.
  • Permissões de acesso às DMVs (em SQL Server 2022+, normalmente VIEW SERVER PERFORMANCE STATE, conforme a consulta e a configuração).
  • As estatísticas top, reads e duration dependem do cache de planos e podem ser zeradas após reinício ou remoção do plano.
  • O comando active pode não retornar linhas quando não houver requisições ativas no banco.
  • O filtro por banco nas estatísticas em cache usa sys.dm_exec_sql_text.dbid; consultas com contexto de banco não disponível podem não aparecer.
  • O código utiliza TrustServerCertificate=Yes para facilitar testes locais; para produção, configurar certificado confiável.
