Vector Database no SQL Server 2025 · Pesquisa e comparação de distâncias vetoriais

Visão geral

Ferramenta de linha de comando, somente leitura, para explorar colunas do tipo VECTOR no SQL Server 2025. Identifica dimensões e tipo-base dos vetores, pesquisa os vizinhos mais próximos e compara as distâncias euclidiana e de cosseno.

v1.0.0 — HOMOLOGADO NO SQL SERVER 2025

Ambiente: Windows x64 · Visual Studio 2022 · C++17 · ODBC Driver 18 · autenticação integrada do Windows.

Comandos

ComandoFinalidade
--helpExibe ajuda e parâmetros.
--versionExibe a versão.
columnsDescobre automaticamente colunas vetoriais no banco.
infoConsulta informações da coluna vetorial de uma tabela.
searchPesquisa vetores próximos, com métrica cosine ou euclidean.
compareMostra as duas distâncias para os registros consultados.

Configuração do laboratório

Servidor.\WSRV25
BancoWX_RECOVERY_LAB
Tabeladbo.WX_Vector_Lab
ColunaEmbedding — VECTOR(3), base float32
Executávelwxt-cpp-053-sql-vector-explorer.exe

Parâmetros opcionais: --server, --db, --table, --column, --metric e --top.

Exemplos — PowerShell

Descobrir colunas vetoriais

E:\@LIB-C++\bin\wxt-cpp-053-sql-vector-explorer.exe columns --server=".\WSRV25" --db="WX_RECOVERY_LAB"

Inspecionar uma coluna

E:\@LIB-C++\bin\wxt-cpp-053-sql-vector-explorer.exe info --table=dbo.WX_Vector_Lab --column=Embedding

Pesquisar por distância de cosseno

E:\@LIB-C++\bin\wxt-cpp-053-sql-vector-explorer.exe search --table=dbo.WX_Vector_Lab --vector="[0.85,0.15,0.1]" --metric=cosine --top=3

Comparar duas métricas

E:\@LIB-C++\bin\wxt-cpp-053-sql-vector-explorer.exe compare --table=dbo.WX_Vector_Lab --vector="[0.85,0.15,0.1]" --top=5

Codificação: o executável emite os textos acentuados em UTF-8. Para visualização correta no PowerShell, execute chcp 65001 antes dos comandos.

Notas técnicas

Os vetores deste laboratório foram definidos manualmente para validar a infraestrutura. Eles não são embeddings gerados por um modelo de inteligência artificial; portanto, o teste demonstra proximidade numérica, não valida a qualidade de uma busca semântica real.

As consultas usam o tipo nativo VECTOR, metadados de sys.columns e a função VECTOR_DISTANCE() do SQL Server 2025. A ferramenta opera somente em leitura.
