Visão geral

Utilitário de linha de comando desenvolvido em C++17 para consultar dados, exportar resultados e copiar registros entre tabelas. O ambiente homologado é Windows x64, Visual Studio 2022, SQL Server 2025 e ODBC Driver 18.

SQL Server 2025 — homologado   PostgreSQL — integração ainda não testada.

Comandos disponíveis

ComandoFinalidade
--help / --versionAjuda e versão do executável
probeVerifica conexão com o banco
tablesLista tabelas; aceita --counts
queryExecuta consulta e exporta em CSV ou JSONL
copyCopia registros usando --append, --truncate ou --create

Exemplo: conexão

E:\@LIB-C++\bin\wxt-cpp-052-db-data-toolkit.exe probe --source="mssql://Driver={ODBC Driver 18 for SQL Server};Server=.\WSRV25;Database=WX_RECOVERY_LAB;Trusted_Connection=yes;TrustServerCertificate=yes"

Exemplo: exportação CSV em UTF-8

E:\@LIB-C++\bin\wxt-cpp-052-db-data-toolkit.exe query --source="mssql://Driver={ODBC Driver 18 for SQL Server};Server=.\WSRV25;Database=WX_RECOVERY_LAB;Trusted_Connection=yes;TrustServerCertificate=yes" --sql="SELECT TOP 5 * FROM dbo.DadosTeste ORDER BY Id" --format=csv --out="E:\@LIB-C++\teste-052-utf8-final.csv"

Resultado verificado: 5 registros; acentuação preservada, confirmada por análise hexadecimal e leitura via PowerShell.

Exemplo: exportação JSONL em UTF-8

E:\@LIB-C++\bin\wxt-cpp-052-db-data-toolkit.exe query --source="mssql://Driver={ODBC Driver 18 for SQL Server};Server=.\WSRV25;Database=WX_RECOVERY_LAB;Trusted_Connection=yes;TrustServerCertificate=yes" --sql="SELECT TOP 5 * FROM dbo.DadosTeste ORDER BY Id" --format=jsonl --out="E:\@LIB-C++\teste-052-utf8.jsonl"

Resultado verificado: 5 objetos JSON válidos, com caracteres acentuados preservados.

Operações de cópia

O comando copy aceita conexão de origem e destino, tabela de origem e destino, além de opções como --batch, --limit e --commit-every.

ModoComportamentoValidação
--appendAdiciona registros ao destino5 registros copiados
--truncateLimpa o destino antes da cópia5 registros finais
--createCria tabela de destino e copia dados5 registros; integridade conferida

Atenção: --truncate remove os dados existentes na tabela de destino. Execute somente em tabelas apropriadas e após confirmar os parâmetros.

Homologação

Testados com êxito: probe, tables, contagens, query CSV/JSONL, modos de cópia, comparação de integridade e validação UTF-8. A validação PostgreSQL permanece pendente e não faz parte desta homologação.
