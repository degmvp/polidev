Visão geral

Ferramenta C++17 que reúne comandos nativos do Linux em operações padronizadas. Executa comandos fixos por fork() e execvp(), sem interpretar entradas como shell. Não instala pacotes, não altera serviços e não modifica arquivos.

Executável Linux: wxt-cpp-055-linux-command-center

No menu interativo, escolha a área pelo número e digite o nome da operação. Na tela de operação, Enter vazio retorna ao menu principal; a opção 0 encerra.

Resultados de homologação

Compilado e executado na VM Ubuntu 24.04 do POLYDEV, com G++ 13.3.0. Foram verificados diagnósticos de sistema, CPU, memória, arquivos, discos, processos e rede, além do menu e da validação de argumentos.

SELFTEST OK (areas=5, operacoes=13, etapas=21)
network / overview
Etapas: 3 | Falhas: 0

O retorno 0 indica execução bem-sucedida; 1, argumentos incorretos; 2, área ou operação inexistente. Quando uma etapa de execução falha, a operação retorna 3.

Observação: Enter vazio no menu principal apresenta “Opcao invalida.”; o comportamento foi registrado como melhoria de usabilidade. Os testes foram realizados na VM do projeto, não em todas as distribuições Linux.

Limitações e segurança

As operações são fixas e somente leitura. Não há editor de comandos arbitrários, execução via shell ou uso de sudo. Os resultados dependem da disponibilidade dos utilitários nativos e das permissões do usuário Linux. O programa apresenta a saída original dos comandos no terminal.
