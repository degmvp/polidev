SQL TempDB Monitor

Monitoramento somente leitura do TempDB do SQL Server, desenvolvido em C++17 para Windows com ODBC Driver 18.

Identificação

Tipo: documentação HTML do utilitário C++17 — não é banner.

Ambiente: Windows / Visual Studio 2022 / SQL Server 2025 / ODBC Driver 18.

Comandos

ComandoFunção
overviewTamanho total dos arquivos de dados e log e quantidade de arquivos.
filesNome, tipo, caminho, tamanho, limite, crescimento e estado dos arquivos.
sessionsAlocações de objetos de usuário e internos por sessão; aceita --limit.
usageEspaço livre, objetos de usuário e internos, version store e extensões mistas.

Execução no PowerShell

E:\@LIB-C++\bin\wxt-cpp-038-sql-tempdb-monitor.exe --help
E:\@LIB-C++\bin\wxt-cpp-038-sql-tempdb-monitor.exe overview --server ".\WSRV25"
E:\@LIB-C++\bin\wxt-cpp-038-sql-tempdb-monitor.exe files --server ".\WSRV25"
E:\@LIB-C++\bin\wxt-cpp-038-sql-tempdb-monitor.exe sessions --server ".\WSRV25" --limit 10
E:\@LIB-C++\bin\wxt-cpp-038-sql-tempdb-monitor.exe usage --server ".\WSRV25"

Homologação — SQL Server 2025

Compilação Release x64 e comandos --help, overview, files, sessions e usage validados na instância .\WSRV25.

Resultados observados: 8 arquivos de dados (64 MB), 1 arquivo de log (8 MB), sessão 73 identificada com 39,06 MB líquidos em objetos de usuário e uso agregado de 41,13 MB em objetos de usuário no TempDB.

Operação somente leitura: o utilitário consulta metadados e DMVs, sem modificar bancos de dados.
