SQL Memory & Buffer Explorer

Ferramenta de diagnóstico somente leitura para memória, memory clerks, buffer pool e pressão de memória no SQL Server 2025. Desenvolvida em C++17 para Windows com ODBC Driver 18.

Identificação

Fonte: wxt-cpp-040-sql-memory-buffer-explorer.cpp

Executável: wxt-cpp-040-sql-memory-buffer-explorer.exe

Plataforma: Windows, Visual Studio 2022 Release x64, SQL Server 2025

Modo: somente leitura (consultas a DMVs)

Comandos

ComandoFinalidade
overviewMemória física do processo SQL Server, memória virtual comprometida, locked/large pages e sinalizadores de memória baixa.
clerksPrincipais memory clerks e caches, páginas alocadas, memória virtual comprometida e AWE; aceita --limit.
buffersPáginas em cache e dirty pages por banco de dados; aceita --db e --limit.
pressureMemória física e pagefile do host, estado de memória, Total/Target Server Memory e concessões de memória pendentes.

Execução no PowerShell

E:\@LIB-C++\bin\wxt-cpp-040-sql-memory-buffer-explorer.exe --help
E:\@LIB-C++\bin\wxt-cpp-040-sql-memory-buffer-explorer.exe overview --server ".\WSRV25"
E:\@LIB-C++\bin\wxt-cpp-040-sql-memory-buffer-explorer.exe clerks --server ".\WSRV25" --limit 10
E:\@LIB-C++\bin\wxt-cpp-040-sql-memory-buffer-explorer.exe buffers --server ".\WSRV25" --db WX_RECOVERY_LAB --limit 10
E:\@LIB-C++\bin\wxt-cpp-040-sql-memory-buffer-explorer.exe pressure --server ".\WSRV25"

Homologação — SQL Server 2025

Compilação e comandos --help, overview, clerks, buffers e pressure validados na instância .\WSRV25.

ComandoResultado observado
overviewMemória física do processo: 1.273,24 MB; memória virtual comprometida: 1.559,54 MB; sinalizadores de memória baixa: 0.
clerks10 memory clerks listados; principais: CACHESTORE_SQLCP (211,56 MB), CACHESTORE_PHDR (189,08 MB), MEMORYCLERK_SQLBUFFERPOOL (178,38 MB).
