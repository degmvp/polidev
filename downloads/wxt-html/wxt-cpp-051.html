JSONL Log Analyzer — C++17
← VOLTAR À WX-TOOLS

Analisa arquivos JSON Lines (JSONL) linha a linha, filtra registros por nível, intervalo de datas e campos, agrega eventos e gera relatórios em texto, CSV ou JSON. A leitura do arquivo de entrada não altera os logs originais.

Comandos

ComandoDescrição
analyzeAnalisa um arquivo JSONL e produz relatório.
selftestExecuta os testes internos.
--helpMostra a ajuda.
--versionMostra a versão.

Opções de análise

OpçãoDescrição
--input FILEArquivo JSONL obrigatório; use - para stdin.
--output FILEDestino do relatório; padrão stdout.
--format text|csv|jsonFormato do relatório; padrão text.
--level LEVELFiltra nível, sem diferenciar maiúsculas/minúsculas.
--from ISO8601Limite inicial inclusivo.
--to ISO8601Limite final inclusivo.
--field KEY=VALUEFiltra um campo escalar; aceita caminho com pontos.
--group-by FIELDCampo para agregação; padrão service.
--level-field FIELDCampo de nível; padrão level.
--time-field FIELDCampo de data/hora; padrão timestamp.
--message-field FIELDCampo de mensagem; padrão message.
--top NLimite de linhas por seção; padrão 10.

Exemplos — PowerShell

E:\@LIB-C++\bin\wxt-cpp-051-jsonl-log-analyzer.exe analyze --input logs.jsonl

E:\@LIB-C++\bin\wxt-cpp-051-jsonl-log-analyzer.exe analyze --input logs.jsonl --level ERROR --format csv --output erros.csv

E:\@LIB-C++\bin\wxt-cpp-051-jsonl-log-analyzer.exe analyze --input logs.jsonl --from 2026-10-16T00:00:00Z --to 2026-10-16T23:59:59Z --field service=api --group-by service --format json --output resumo.json

E:\@LIB-C++\bin\wxt-cpp-051-jsonl-log-analyzer.exe selftest

Validação e segurança

Registros JSON inválidos são contabilizados e ignorados. Os timestamps aceitam o formato ISO 8601 com fuso UTC (Z) ou offset explícito (+/-HH:MM). A ferramenta não modifica o arquivo de entrada.
