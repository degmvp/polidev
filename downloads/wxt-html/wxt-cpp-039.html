SQL Transaction Log Explorer

Exploração somente leitura dos logs de transações do SQL Server, desenvolvida em C++17 para Windows com ODBC Driver 18.

Identificação

Tipo: documentação HTML do utilitário C++17 — não é banner.

Ambiente: Windows / Visual Studio 2022 / SQL Server 2025 / ODBC Driver 18.

Comandos

ComandoFunção
overviewModelo de recuperação, motivo de espera para reutilização do log, tamanho total e ativo, total de VLFs e VLFs ativos.
filesNome e caminho do arquivo de log (.ldf), tamanho, limite, crescimento automático e estado.
usageTamanho total e utilizado do log, percentual de utilização e volume gerado desde o último backup de log.
vlfsInspeção dos Virtual Log Files: offsets, tamanhos, estado, atividade e sequência; aceita --limit.

Execução no PowerShell

E:\@LIB-C++\bin\wxt-cpp-039-sql-transaction-log-explorer.exe --help
E:\@LIB-C++\bin\wxt-cpp-039-sql-transaction-log-explorer.exe overview --server ".\WSRV25" --db WX_RECOVERY_LAB
E:\@LIB-C++\bin\wxt-cpp-039-sql-transaction-log-explorer.exe files --server ".\WSRV25" --db WX_RECOVERY_LAB
E:\@LIB-C++\bin\wxt-cpp-039-sql-transaction-log-explorer.exe usage --server ".\WSRV25" --db WX_RECOVERY_LAB
E:\@LIB-C++\bin\wxt-cpp-039-sql-transaction-log-explorer.exe vlfs --server ".\WSRV25" --db WX_RECOVERY_LAB --limit 10

Homologação — SQL Server 2025

Compilação Release x64 e comandos --help, overview, files, usage e vlfs validados na instância .\WSRV25 e banco WX_RECOVERY_LAB.

Resultados observados: recuperação FULL; log de 135,99 MB; 2,07 MB de log ativo; 6 VLFs, dos quais 1 ativo; arquivo de log ONLINE com crescimento de 64 MB; 40,40 MB utilizados (29,71%) e 2,06 MB gerados desde o último backup de log.

Operação somente leitura: consulta metadados e DMVs sem modificar o banco. Algumas DMVs exigem permissões de visualização de estado/desempenho.
