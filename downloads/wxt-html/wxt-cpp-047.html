Encoding Toolkit — C++17
Menu WX-TOOLS

Utilitário de linha de comando para codificar e decodificar Base64, Base32, hexadecimal (Base16) e URL percent-encoding, com leitura e escrita em streaming.

Comandos

ComandoFunção
encodeConverte bytes para representação codificada.
decodeRestaura os bytes originais com validação da entrada.
selftestExecuta verificações internas com vetores RFC e roundtrips.

Exemplos no PowerShell

E:\@LIB-C++\bin\wxt-cpp-047-encoding-toolkit.exe --version
E:\@LIB-C++\bin\wxt-cpp-047-encoding-toolkit.exe selftest
E:\@LIB-C++\bin\wxt-cpp-047-encoding-toolkit.exe encode --algo=base64 E:\@LIB-C++\msg.txt
E:\@LIB-C++\bin\wxt-cpp-047-encoding-toolkit.exe encode --algo=hex --upper E:\@LIB-C++\msg.txt
E:\@LIB-C++\bin\wxt-cpp-047-encoding-toolkit.exe decode --algo=base64 E:\@LIB-C++\msg.b64 --out=E:\@LIB-C++\restaurado.bin

Opções principais

--algo=base64|base32|hex|url, --out=FILE, --wrap=N (Base64/Base32), --upper (hex), --url-safe (Base64 encode), --form (URL).
